## Bundled AI provider CLI

The api image installs the [**Claude Code CLI**](https://github.com/anthropics/claude-code)
(`@anthropic-ai/claude-code`, pinned in `api/Dockerfile`) so the optional AI Coach works
without the instance owner installing anything. 2J Fitness Center invokes it as a separate process at
runtime and does not link against it or include its source; this is mere aggregation, and
2J Fitness Center's own AGPL v3.0 licensing is unchanged.

The CLI is distributed under its own terms, and using it requires an account with the
provider. Both are matters between the instance owner and Anthropic — 2J Fitness Center ships no
credentials and asks its users for none. Instances that would rather not carry it can leave
the Coach disabled (the default) or set `COACH_DISABLED=1`.

## Exercise data & media

The exercise records and non-media instructions originate from
[**hasaneyldrm/exercises-dataset**](https://github.com/hasaneyldrm/exercises-dataset). Its current
[`LICENSE`](https://github.com/hasaneyldrm/exercises-dataset/blob/7455efae41b330c265e7cd4b78dfa848e7ce5ebd/LICENSE) and
[`NOTICE.md`](https://github.com/hasaneyldrm/exercises-dataset/blob/7455efae41b330c265e7cd4b78dfa848e7ce5ebd/NOTICE.md) at the media revision used by the mobile build place the
non-media dataset under MIT. This is separate from openGym's AGPL-3.0-or-later application code,
and from 2J's taxonomy, aliases and protocol decisions.

The dataset JPG thumbnails and GIF animations are **not covered by MIT**. The upstream license
and notice identify them as © Gym visual, say the dataset repository has separate written
permission, require the attribution `© Gym visual — https://gymvisual.com/`, limit the copies to
180 × 180, and direct downstream users to Gym visual's terms and to obtain their own permission.
Cloning the dataset does not grant 2J those rights. No direct 2J permission/license evidence is
recorded here, and the revision used to populate the old untracked runtime `media/` directories
was not pinned. The app therefore hides this family by default, Nginx returns 404 for its paths,
and Compose no longer downloads or mounts it. Existing local media files are not deleted.

The 157 tracked stretching illustrations have a source comment saying Juanjo supplied them, but
the repository has no creator or license record. They are classified `UNKNOWN_OR_UNVERIFIED`,
hidden by the UI and blocked from serving until rights are documented. See the asset-level ledger
[`docs/legal/exercise-media-inventory.csv`](docs/legal/exercise-media-inventory.csv), generated by
`scripts/build-exercise-media-inventory.mjs`.
